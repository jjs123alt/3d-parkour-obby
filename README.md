# 3D Parkour Obby

A browser-based 3D parkour course with mouse look, multi-level progression, and platform jumping.

## Run it

Use a local web server:

```bash
python -m http.server 8000
```

Then open:

```text
http://localhost:8000
```

## Controls

- W/A/S/D: Move
- Space: Jump
- Mouse: Look around
- Click: Capture mouse

## Features

- 3D first-person camera
- Several platforming levels
- Smooth jump physics
- finish platform progression
- HUD with speed, height, and timer
- polished lighting and environment
